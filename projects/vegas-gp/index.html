## The question

I went to the Las Vegas Grand Prix in 2025 as a fan. This year I wanted to see if a model could call the podium before the race.

## The data

All 20 Grands Prix of the 2026 season, pulled into R with the `f1dataR` package: [440 driver-race rows]{.stat}. I used only 2026 because the cars run under brand-new regulations this year, so older seasons describe different cars.

## The model

A logistic regression trained on who made the podium, using five features:

| Feature | Variable |
| --- | --- |
| Starting position | `grid` |
| Last 3 finishes | `form3` |
| Team strength | `team_form` |
| Reliability | `dnf_rate` |
| Fast, low-downforce street tracks like Vegas | `low_df` |
